# Ground impressions, replacing ribbon tracks

The original separate wheel ribbons produced rectangular carpet edges, phase jumps and doubled chevrons. They have been replaced with one rolling 16 m height/compaction mask shared by all six wheels. Its 1024-pixel sampling is a cosmetic raster, not new geographic resolution.

Grounded wheel travel stamps soft rounded footprints into the mask. Tread phase follows integrated path length rather than projecting each segment onto world coordinates. Overlapping passes combine maximum compaction and the deeper impression, without stacking surfaces. Turns and reversing use the same mask. Recovery jumps reset the path connection.

Each touched 4 m tile is prepared on a worker with 128 subdivisions per side (3.125 cm mesh spacing). Underlying heights still come from the shared terrain service. Tile boundaries blend into the parent’s 1 m visual mesh. Only touched parent chunks are held at that resolution. The original ground is hidden in a tile only after its replacement mesh and mask are ready; failed preparation retains the original ground. At most 16 dense tiles and one preparation thread exist. Moving the 16 m window preserves overlapping mask pixels and removes expired tiles.

Dense patches use the existing sourced imagery, cavity map and cinematic material rather than a separate brown track texture. The mask modifies vertex height, surface normals, compaction shading and roughness. Compressed areas have reduced illustrative microdetail; the soft track footprint blends into untouched ground. Visual depression reaches about 15 mm, with shoulders near 3 mm. These values are illustrative styling, not measured sinkage or a terramechanics model. Source appearance removes the cosmetic displacement and restores the original terrain rendering. Measured terrain APIs, collision, navigation and source data remain unchanged.

Cosmetic pebbles inside footprints are hidden through the same mask, preventing floating pebbles in ruts. Larger collision rocks remain. This does not simulate pushed stone trajectories or displaced soil mass. Tracks do not persist to disk, and history expires outside the rolling window. Very steep terrain and coarse source interpolation retain their existing accuracy limits. GPU hardware tessellation is not used.

Files: `wheel_tracks.gd` manages stamps, streaming and replacement readiness; `track_mask.gdshaderinc` supplies shared mask sampling; `surface.gdshader` applies displacement and shading to ready dense patches; `rock.gdshader` hides traversed cosmetic pebbles. `detail_renderer.gd` holds touched parent resolution. `mission_world.gd` binds the current materials and Source appearance. Appearance/material changes do not rewrite measured geometry or collision artifacts.

The targeted `tests/track_impressions.gd` exercises driving, turning, reversing, shared-mask identity, idempotent overlaps, ready replacement tiles, bounded memory, collision hashes, centimetre visual sampling and source/cinematic switching. It captures all three requested resolutions, overhead and close-up views in both renderers. Earlier ribbon screenshots and measurements remain historical evidence and do not describe this implementation.

The final renderer passes each recorded 12 successful assertions, with actual renders at all three sizes. Four separate numeric mask checks passed: idempotent repeated stamps, surviving longitudinal tread variation, phase continuity across split segments and order-independent crossings. Visual review exposed overly faint compression and then tread flattening caused by excessively long stamp end caps; these were corrected before the final screenshots. The final crossing-priority correction was checked numerically rather than repeating the full graphical batch. Source appearance and collision hashes remain intact. First preparation can delay marks while parent meshes reach the required spacing; the ground remains visible throughout.

Five-second moving-camera observations at 1600x900 measured median/p95 **17.12/26.10 ms in Compatibility** and **53.16/166.25 ms in experimental Forward+**. Resting static memory was about 438/465 MiB respectively, with roughly 246/399 MiB texture memory reported separately. These short samples include laptop variability and an unrelated existing game instance; they are not isolated benchmarks or stable-60-FPS certification. Forward+ remains substantially slower and is not the default. Existing GL texture/ObjectDB shutdown warnings remain. One Compatibility run also emitted a Jolt job-capacity warning; no production script or shader compilation errors remained.

Evidence: `evidence/track_impressions_gl_compatibility.json`, `evidence/track_impressions_forward_plus.json`, `evidence/track_mask_numeric.json` and the `dusty_impressions_*` images. Track preparation/upload timing has not been isolated from total frame time; the 2 ms upload target is not certified for dense impression meshes.
